# 信令协议

默认连接 `ws://<host>:8090`（`--port` 可改）。控制面是 UTF-8 JSON 文本帧，信封为 `{"type":"...", ...}`；媒体面是二进制帧，服务端只做校验和转发。

连上后服务端先发：

```json
{"type":"hello","version":"0.1.0"}
```

## 客户端 → 服务端

| type | 字段 | 说明 |
|------|------|------|
| `create_room` | `name` | 创建房间，创建者为主持人 |
| `join_room` | `room_id`, `name` | `room_id` 会去掉空格和短横线 |
| `leave_room` | — | 离开当前房间 |
| `set_state` | `mic`?, `cam`? | 只传变化字段 |
| `set_share` | `on` | 屏幕共享开关 |
| `chat` | `text` | 聊天 |
| `ping` | — | 心跳，回复 `pong` |

## 服务端 → 客户端

| type | 字段 | 说明 |
|------|------|------|
| `hello` | `version` | 建连后立即下发 |
| `room_created` | `room_id` | 仅发给创建者 |
| `joined` | `room_id`, `member_id`, `members[]` | 发给入会者，带房间全量列表 |
| `member_joined` | `member` | 广播新人 |
| `member_left` | `member_id` | 广播离开 |
| `member_updated` | `member_id`, `mic`, `cam`, `sharing` | 广播状态 |
| `chat` | `member_id`, `name`, `text` | 广播聊天 |
| `room_closed` | — | 主持人离开或房间空 |
| `error` | `code`, `message` | 发给单个客户端 |
| `pong` | — | 对应 `ping` |

`member` 对象：

```json
{"id":"m1","name":"张伟","mic":true,"cam":true,"sharing":false,"isHost":false}
```

## 房间规则

- 房间号 9 位数字，写入协议时用连写（界面可显示成 `882 536 419`）
- 上限 49 人
- 主持人离开或房间空：广播 `room_closed` 并销毁房间
- 120 秒无任何消息则断开，建议 30 秒一次 `ping`
- 错误码：`already_in_room` / `room_not_found` / `room_full` / `bad_request`

## 媒体帧

信封：

```
[4 字节大端 headerLen][header JSON UTF-8][payload]
```

header 由发送方填写，服务端转发时注入 `member_id`：

```json
{"kind":"video","w":640,"h":480}
{"kind":"audio"}
{"kind":"screen","w":1920,"h":1080}
```

| kind | payload | 说明 |
|------|---------|------|
| `video` | JPEG | 摄像头，约 10 fps，宽 ≤ 640 |
| `audio` | PCM Int16 | 44.1 kHz 单声道 |
| `screen` | JPEG | 屏幕共享，约 4 fps，宽 ≤ 1280 |

发送者必须已在房间内。注入 `member_id` 后转发给同会其他人，不含自己。单帧上限 8 MB。不做丢包重传或拥塞控制。
